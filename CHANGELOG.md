# Changelog

## [1.0.0] - 2026-03-25

### Added
- Multi-tenant architecture with path-based and subdomain tenancy
- Microsoft Entra ID and Google OIDC authentication
- Local username/password authentication (dev mode)
- Dashboard with funding summary, C2 budget bar, deadlines, activity feed
- District profile management with schools and funding years
- C2 Budget Tracker with auto-calculation (FY2021-2025 and FY2026-2030 rates)
- Application lifecycle tracker (Form 470, Form 471/FRN, invoices, appeals)
- Deadline calendar with monthly and list views
- Vendor and contract management with renewal alerts
- Document repository with Cloudflare R2 storage and local fallback
- Compliance and audit readiness checklists
- PDF report generation (annual summary, deadlines, documents, vendors)
- Platform admin panel with tenant management and impersonation
- Audit logging for all state-changing operations
- Docker Compose deployment with PostgreSQL and Cloudflare Tunnel
- Demo seed data command
