About Backups

Backups include all your E-Rate data:

  • Schools and district profile
  • Funding years and discount rates
  • FRNs, Form 470s, invoices, appeals
  • Form 486 records
  • Vendors and contracts
  • Calendar events and deadlines
  • C2 budget data
  • Document metadata (not file contents)
  • User accounts (not passwords)
Backups are stored in {% if backups and backups[0].storage == 'r2' %}Cloudflare R2{% else %}local server storage{% endif %}.
